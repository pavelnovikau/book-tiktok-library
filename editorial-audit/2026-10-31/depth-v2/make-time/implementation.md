# Book-local implementation

Only this new `depth-v2/make-time/` directory was authored. No Git commands, checkout/worktree creation, publication, catalogue/root-reader/shared-shell/installed-skill changes, parent dispatch/status/PLAN/log edits, or delegation occurred.

RU was drafted as 66 connected two-paragraph explanatory units before segmentation. EN follows the same substantive units. Each unit becomes one scrollable reading screen, with a separate typographic cover and a short shared final. Units retain stable shared RU/EN IDs, levels and actual primary ranges. No screen/word quota was enforced: 24/48/68 is the measured nested result. The 9,900-word RU main body is approximately the proposed planning scale; omissions remove ornament, repeated exhortations, unsupported illustration detail and nonessential effect figures instead of padding to a threshold.

`reader/` contains byte-identical copies of the maintained installed book-tiktok builder, template, Settings, header and licensed offline fonts. `build.mjs` locally reuses the accepted expanded nonfiction wrapper from the Kahneman candidate, pointing it to those private local copies. It does not copy another book's HTML or corpus.

Local patches are limited to a typographic cover hiding the template's unrelated generic model decoration, the `book-tiktok.make-time.depth-v2.` progress namespace, correctly inflected Russian reading-minute labels, and explicit deeper Continue labels. The latter names the actual Core/Deep route even if that route was already selected, and also handles a lower selected mode with a deeper remembered ID. This nonfiction has `spoilerPolicy: not-applicable`; it does not open a fiction-ending consent dialog. Global theme/font preferences retain `bookLibrary.preferences.v1`. Fresh reading starts RU/dark/Sans/Essential; valid existing global preferences persist.

`prepare.py` derives story data, six routes and initial coverage from the completed drafts. `coverage-details.py` adds the individual 87-tactic retention/compression explanations. `build.mjs` builds only the local HTML. `browser-check.mjs` runs a no-server offline CDP check with a unique mktemp profile, timeout 30 and a dedicated process group, cleaned in finally. `measure.mjs` checks exact draft/body/embedding/route parity, nested IDs, real metrics and unchanged read-only inputs. `write-handoff.py` writes records and the final SHA-256 manifest. Run coverage-details once after prepare; it appends its detailed Markdown section.

A final local rebuild sequence is `python3 prepare.py`, `python3 coverage-details.py`, `node build.mjs`, followed by the local audit and browser checks, `node measure.mjs`, then `python3 write-handoff.py`. No build command requires a server, external runtime fetch, or edits beyond this directory. No screenshot/Chrome emulation is physical Safari certification.
